# 💰 Spendwise - Personal Expenses Tracker with ML Prediction

An interactive desktop application built using Python, Tkinter, SQLite, and Scikit-Learn that allows users to track daily expenses and predict future spending trends using Machine Learning.

---

## 🚀 Key Features

* **Expense Management:** Record daily transactions with details like date, category, description, and total amount.
* **Category Tagging:** Organize spending into presets such as Food, Transport, Shopping, Bills, and Entertainment.
* **History Log:** View and navigate past expense records through an interactive UI table.
* **Delete Records:** Easily modify or delete incorrect transaction entries.
* **Real-time Total Tracker:** Automatically sums up total expenditure dynamically.
* **🔮 ML Expense Prediction:** Leverages a Linear Regression model to analyze historical spending patterns and predict estimated expenses for the upcoming month.
* **Persistent Database:** SQLite engine ensures transaction history is safely stored locally.

---

## 🛠️ Tech Stack & Libraries

* **GUI Framework:** Python Tkinter
* **Database Engine:** SQLite3
* **Data Processing:** Pandas, NumPy
* **Machine Learning:** Scikit-Learn (Linear Regression Model)
